# Build Your First Personalized Copilot

A beginner-friendly, offline, static web tutorial for personalizing Microsoft Copilot with Custom Instructions.

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

> The complete tutorial lives in the [`digital-twin-tutorial/`](digital-twin-tutorial/) folder.

---

## What’s Inside

```text
DigitalTwin/
├── README.md                    <- this file
├── LICENSE                      <- Creative Commons Attribution 4.0
└── digital-twin-tutorial/       <- the tutorial itself
    ├── index.html               <- the full tutorial page
    ├── styles.css               <- responsive workshop design
    ├── script.js                <- copy buttons, progress tracking, notes, and print behavior
    ├── images/                  <- tutorial illustrations and screenshots
    ├── README.md                <- detailed setup and customization guide
    └── CHANGELOG.md             <- history of changes
```

The tutorial walks learners through a practical Microsoft Copilot personalization workflow:

1. Decide what Copilot should know.
2. Decide how Copilot should respond.
3. Create one Custom Instructions block.
4. Add the instructions to Copilot.
5. Test the personalization.
6. Improve the instructions.
7. Review limits and privacy.
8. Keep the setup current.

The tutorial focuses on Copilot Custom Instructions: selected background information, response preferences, and privacy-conscious boundaries that learners control and update.

## Download the Repository as a ZIP

You do not need a GitHub account or any tool to use this tutorial. Two easy ways to download the whole repository as a ZIP file:

### Option 1 - From the GitHub Website

1. Open the repository page:
   **https://github.com/nmatsui7/DigitalTwin**
2. Click the green **Code** button near the top of the file list.
3. In the dropdown, click **Download ZIP**.
4. A file named `DigitalTwin-main.zip` is downloaded to your computer.

### Option 2 - Direct Download Link

Click or copy this URL into your browser to download the same ZIP without visiting GitHub:

```text
https://github.com/nmatsui7/DigitalTwin/archive/refs/heads/main.zip
```

### Unzip and Open

1. Double-click the ZIP to extract it.
2. Open the extracted folder, then open `digital-twin-tutorial/`.
3. Double-click `index.html`; it opens in your default browser.

Keep the folder together so `index.html`, `images/`, `styles.css`, and `script.js` keep working.

## Tech Notes

- **Static and private:** no server, no database, no API calls, and no CDNs.
- **No build step:** edit the text directly in `digital-twin-tutorial/index.html`.
- **Accessible:** keyboard-navigable, screen-reader-friendly alt text, and a no-JavaScript notice.

See [`digital-twin-tutorial/README.md`](digital-twin-tutorial/README.md) for the full customization and testing guide.
